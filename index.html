FAQ

Do I need to buy hosting?

No. Use free GitHub Pages or Netlify Drop, or open the HTML locally while you edit. Custom domains are optional later and not required to sell or use the kit.

How technical is this?

If you can edit text in a file and drag a folder onto Netlify Drop, you’re fine. Templates are plain HTML + CSS. No build step, no Node, no paid CDN.

Will the email form collect leads out of the box?

Not until you wire it. Each template ships with a clearly marked placeholder. Connect Beehiiv / Buttondown / Mailchimp / ConvertKit or a form endpoint using the included snippets guide.

Can I use a custom domain later?

Yes. Point a domain at GitHub Pages or Netlify when you’re ready. The kit does not sell or register domains.

Is this a Linktree / Stan Store replacement?

It’s an ownable static alternative for links + lead capture. It is not a marketplace, payment processor, or analytics suite.

Commercial / client use?

License is personal use for your own bio. If you need client / agency rights, email and ask — don’t assume.
